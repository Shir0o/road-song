# Multimodal Trip Narrative Extraction & Rhyming Lyricist Schema

`wayfinder:research`

## Question

How should multimodal media assets (photos, video frames, transcribed voice notes, typed logs) be clustered, summarized, and prompted into Gemini to generate a structured, hilarious, rhyming song lyric document with explicit musical section tags, rhythm meter hints, and named participant callouts?

## Scope & Deliverables
1. Multimodal clustering & narrative arc generation algorithm (Beginning/Intro -> Rising Chaos/Verses -> Peak Highlight/Chorus -> Outro).
2. Prompt engineering & structured JSON output schema for rhyming lyrics with syllable counts, mood tags, and character mentions.
3. Fallback strategy when input evidence is sparse or unbalanced.
