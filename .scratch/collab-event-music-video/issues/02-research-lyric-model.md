# 02: Choose the lyric structuring model

Type: research
Status: open
Blocked by:

## Question

Which LLM should generate the structured lyric sheet (verses, chorus, rhyme, meter, and dynamic tags like `[Verse]` / `[Chorus]`)?

Compare Claude 3.5 Haiku, GPT-4o-mini, and Gemini 2.0 Flash on:
- Adherence to strict metrical counts and rhyme schemes.
- Structured output reliability (tags, sections, line breaks).
- Cost and latency per lyric generation.
- Fit with the downstream syllable-locking editor.

## Notes

- The brief lists Claude 3.5 Haiku / GPT-4o-mini as candidates.
- This decision feeds the lyric sandbox and story-to-lyrics pipeline.
