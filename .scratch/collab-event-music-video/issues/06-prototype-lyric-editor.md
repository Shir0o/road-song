# 06: Prototype the Lyric Sandbox editing experience

Type: prototype
Status: open
Blocked by: 02, 05

## Question

What should the line-by-line lyric editor feel like, including syllable locking and phonetic name corrections?

Create a cheap, rough prototype to react to:
- Line-by-line editing with visual feedback on syllable counts and rhyme.
- How "syllable locking" is presented and enforced.
- Phonetic name correction UX (e.g., fixing how a name is sung/pronounced).
- Where the structured tags (`[Verse]`, `[Chorus]`) appear and how they can be edited.
