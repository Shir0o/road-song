# 04: Design the no-account Magic Link / QR ingestion flow

Type: grilling
Status: open
Blocked by: 05

## Question

How should organizers create an event space and friends join/contribute without creating accounts?

Decide:
- Does the organizer need an account, or can they also be anonymous?
- Magic Link delivery (email/SMS?) vs QR code only; link expiry and reuse.
- What a contributor can do (upload, caption, vote on prompts) and for how long.
- Privacy boundaries: who can see what, and how media is protected.

## Notes

- Frictionless ingestion is the core first step of the user journey.
- This blocks the uploader implementation.
